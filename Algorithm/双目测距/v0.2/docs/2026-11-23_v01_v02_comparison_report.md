# v0.1与v0.2算法横向比较

日期：2026-11-23。本次仅核对代码、整理已有结果，未修改算法或重新调参。按项目开发约定区分输出率、共同样本误差和实验分支。

## 1. 版本边界

v0.1包含三个阶段，不能全部简称为SGBM：原SGBM主流程、可选独立反查、后期局部NCC实验。v0.2方案A复用了最后一项NCC，再加入Shi–Tomasi主动选点；不是在SGBM内部添加角点模块。

主对比为v0.1原SGBM与v0.2方案A；另以v0.1网格NCC为中间对照，区分“换匹配器”与“换选点”的作用。椅子7类ROI试验单列，不算方案A自动选区的成绩。

## 2. 两条主流程

- v0.1：校正左右图 → 全图SGBM → 过滤无效视差和边界 → Q换算深度 → 人工ROI内取中位数。ROI可先框好，但不限制全图匹配计算范围。
- v0.2：校正左右图 → 人工ROI → Shi–Tomasi角点及分区名额 → 弱纹理筛选 → NCC在右图横向及上下窄带搜索 → 最佳/次佳筛选 → 完整二维对应三角化 → ROI所选点深度中位数。

两者都使用同一5.85cm相机参数、640×480图像，主比较距离均为矫正左坐标Z。均尚未自动识别目标或生成目标ROI，均没有按物体归属分割后再统计。

## 3. 算法作用、逻辑和差别

| 环节 | v0.1原SGBM | v0.2方案A |
| --- | --- | --- |
| 选择位置 | 不预先挑角点，计算全图视差 | 人工ROI内先挑角点，只计算选中位置 |
| 外观比较 | OpenCV SGBM使用内置Birchfield–Tomasi匹配度量及块比较 | NCC比较去平均亮度并归一化后的图块结构 |
| 候选搜索 | 校正图的同一行 | 同一行附近上下各8像素 |
| 邻域约束 | 多方向累计代价，P1/P2惩罚邻近视差变化 | 当前逐点比较，无SGBM式的多方向联合优化 |
| 筛选 | 唯一性、散斑、正视差、有限正深度、真实图像及窗口支持等 | 角点质量/间距，图块纹理、相关分数、最佳次佳差、搜索边界等 |
| 深度计算 | Q重建 | P1/P2对左右完整二维坐标三角化，同时记录投影残差 |
| 汇总 | ROI内有效稠密像素深度中位数 | 选中并成功匹配的稀疏点深度中位数 |
| 输出门槛 | 至少30像素、ROI像素有效比例10% | 至少30有效点、所选点通过比例10% |
| 结果形态 | 全图较密集的视差/深度及ROI距离 | 目标ROI内稀疏对应坐标、得分、拒绝原因和距离 |

SGBM的多方向是代价聚合方向，不是允许对应点在上下行搜索。三角化能够保存并使用二维对应，但不自动消除现有模型的上下残差。

官方原理参考：[SGBM](https://docs.opencv.org/4.x/d2/d85/classcv_1_1StereoSGBM.html)、[NCC公式](https://docs.opencv.org/4.x/df/dfb/group__imgproc__object.html)、[Shi–Tomasi](https://docs.opencv.org/4.x/d4/d8c/tutorial_py_shi_tomasi.html)。

### SGBM的特点

优点：可以输出全图较密集的距离；利用邻近位置约束选择视差，弱纹理区域也可能借助周围结构得到结果；适合先观察场景整体深度，现有书本结果较完整。

不足：当前输入仍有上下残差，同一行搜索可能找错；边界和遮挡会让窗口混合不同物体。平滑约束和大量有效点也可能形成连贯但错误的深度。计算整幅图，不能因为最后只取一个小ROI就自动节省匹配工作。

### Shi–Tomasi与局部NCC的特点

Shi–Tomasi寻找两个方向都能定位的灰度变化，先跳过很多不容易匹配的位置；3×3分区和点间距控制聚集。它不是物体识别，也不保证角点在右图有唯一对应。

NCC比较相对明暗结构，能减轻两图整体亮度/对比度差异；窄带搜索使上下有少量偏移的候选进入比较，逐点得分和拒绝原因易查看。

优点：可把计算集中在目标区域，保留可解释的二维对应；主动选点较同数量均匀网格更容易得到足够有效点。

不足：角点可能太少，也可能位于重复网纹；没有多方向联合优化，局部相似候选容易互相混淆。上下搜索扩大候选范围同时会增加歧义。少量点可能不代表整个物体；当前30点门槛会使远处小目标不输出。

## 4. 关键参数

| 参数作用 | v0.1原主流程值 | v0.2方案A值 |
| --- | --- | --- |
| 匹配窗口 | SGBM块边长5像素 | NCC块边长9像素 |
| 横向搜索 | 最小0、范围宽128，过滤后只用正视差 | 正视差1～127像素 |
| 纵向搜索 | 同行 | ±8像素 |
| 邻点惩罚 | P1=200，P2=800，限制视差跳变 | 未实现相同聚合惩罚 |
| 匹配筛选 | uniqueness_ratio=10，散斑窗口100，散斑范围2 | 灰度标准差≥5、NCC≥0.75、最佳次佳差≥0.03 |
| 主动选点 | 无 | 相对角点质量0.01，间距3像素，角点窗口3，3×3名额分区 |
| 数量/比例 | 30像素及10% | 30点及10% |

v0.1的disp12_max_diff=1是SGBM内置检查；后来另加的独立完整右视差反查是可选分支，不能混为一项。v0.2方案A不运行这个独立反查。

## 5. 同批43对结果

| 目标 | v0.1原SGBM输出 | v0.2主动点输出 | 比较样本 | v0.1平均绝对误差 | v0.2平均绝对误差 |
| --- | --- | --- | --- | --- | --- |
| 书本 | 25/25 | 19/25 | 共同19对 | 8.26 cm | 8.49 cm |
| 人物 | 9/9 | 9/9 | 全部9对 | 32.17 cm | 26.46 cm |
| 椅子 | 9/9 | 0/9 | 无共同输出 | 不作共同精度比较 | 无 |

书本全部25对的v0.1误差12.48cm，不能直接与v0.2较少19对的8.49cm比较后宣称改善。v0.2缺失的6对包含全部3米书本；这些样本的诊断深度仍偏近。

v0.1椅子9对虽然全部有距离，平均误差约210.65cm，近1米组曾测出5米左右；v0.2没有可靠距离输出。因此两版椅子都未成功，但失败方式不同：一版多为错误输出，另一版为可靠点不足。

## 6. 人物改善来自哪一项

v0.1后期网格NCC已经在共同8对人物上把原SGBM误差从33.97降至27.90cm。v0.2主动选点对这相同8对为27.70cm，只有约0.20cm差异；新增收获是原网格NCC未输出的0003可以输出。

书本共同19对，原网格NCC为8.37cm，主动角点8.49cm，也没有精度提升。

相同较少点数的网格对照共有20/43对输出，主动点为28/43；这支持“选点效率更好”，不支持“选点让深度整体更准”。

## 7. 其他分支不能当作版本总成绩

独立反查：43对变成41对输出；在共同41对上，平均误差44.68→93.60cm，主要受椅子0012筛点后错误深度占多数、输出24.30m影响。它未证实改善当前整体精度。

椅子ROI实验：不同人工边框中，网格NCC在6对出现可输出候选。但这不是同一个自动规则产生的6/9成功率，也不是Shi–Tomasi方案A的结果。局部框、面积、点数和测量表面变化的影响需分开分析。

ROI方面两版共享人工输入局限：原椅背上沿最窄8像素，甚至小于v0.2的9×9窗口。这个设计没有充分考虑窗口对表面的覆盖，限制了此前椅子试验结论。更换ROI后仍有错配，说明不能只归因于选区。

## 8. 代价与实用性

v0.1原流程本机读图及计算平均约108ms/对；独立反查约177ms/对。v0.2主动选点平均约5.6ms，NCC稀疏匹配约9.3ms，二者合计约14.9ms；它没有计入读图、校正、三角化和写盘，不能据此声称比v0.1整套系统快7倍。

相同ROI的固定网格NCC匹配约21.6ms，主动点的选点加匹配约14.9ms，反映了减少点数的计算收益。本轮没有树莓派速度或连续图像延迟测试。

## 9. 当前判断

- v0.1适合作为全图深度及书本测距基线，输出较完整，但输出率不是准确率。
- v0.2适合研究稀疏目标测距、选点效率和局部对应解释；人物有部分改善，但主要改善已在NCC阶段出现，尚不能称为全面优于v0.1。
- 椅子两版均未解决。应先按已提交的固定ROI规则方案分清区域与匹配因素，暂不预设主流程必须换成主动角点。

后续候选及参数已列于 [ROI归因开发方案](2026-11-23_roi_attribution_plan.md)，仍待批准。本次不新增实施方向或试验。
