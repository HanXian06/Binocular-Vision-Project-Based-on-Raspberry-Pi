# v0.1 已采集数据集整体测距评估

日期：2026-11-20。状态：本轮测试完成，等待审阅改进方案。版本仍为 v0.1。

## 1. 这次做了什么

使用当前的固定相机参数（基线 5.85 cm）、640×480 原图和现有 StereoSGBM，逐对完成“校正 → 视差 → 深度 → 物体表面 ROI 中位数”。没有改变算法文件、匹配参数、区域门槛或原有结果字段。

覆盖 `Dataset/Data1105` 中全部有测距参考记录的图片：PartB 25 对纸盒，PartC 9 对人物、9 对椅子，共 43 对。PartA 的 20 对棋盘格没有目标距离记录，不计入测距误差；早期 Data1029 棋盘格也不计入。本轮不重新标定，不要求补拍。

参考距离依据 ReadmeB、ReadmeC 和原任务单整理，属于采集时的近似记录。PartB 每组按“基准、+1、−1、+2、−2 cm”；PartC 人物按“基准、+2、−2 cm”，椅子按“基准、+1、−1 cm”。PartC 根据照片中的目标和拍摄顺序，解释为“1米人物、1米椅子、2米人物、2米椅子、3米人物、3米椅子”，每组3对。这些误差适合用于当前开发比较，尚不是独立测试集的精度验收结果。

ROI 在计算距离前确定：纸盒取正面内部，人物取躯干衣服表面，椅子取靠背上端材料表面。纸盒先根据红色外观生成内缩建议框，再逐张看图确认；人物与椅子直接看校正左图选框。没有按深度结果重选 ROI。椅背上沿较窄，框高为 8～12 像素，这是本轮测量表面的实际限制。PartB/0006 沿用之前样例的原框。

ROI 的坐标、参考距离、目标类别见 [固定标注](../evaluation/roi_annotations.json)。框位总览：纸盒（历史本地材料未随发布副本携带）、人物与椅子（历史本地材料未随发布副本携带）。

## 2. 结果怎样读

“平均测得距离”是同组结果的平均数；“平均绝对误差”先对每对图片与其各自参考值作差、取绝对值，再求平均；“平均相对误差”将每对绝对误差除以其参考距离再平均。不是用组平均值代替逐对比较。

43/43 对都满足现有输出门槛（至少30个有效像素、有效比例至少10%），但只有27对的相对误差在10%以内，36对在20%以内。10%/20%仅用于本次观察误差分布。**能输出距离，不等于匹配正确。**

纸盒25对全部偏近。由近到远，平均绝对误差从约3.1 cm增至28.0 cm，平均相对误差约5.4%～9.3%。因此，先前单张1米样例的约3.5 cm误差，不能代表整组或远距离表现。纸盒25对平均绝对误差12.5 cm，平均相对误差7.1%。

人物9对平均绝对误差32.2 cm，平均相对误差15.9%。其中3米组的 `PartC/pair_0015` 明显偏离另外两张，是后续匹配改进的重要对照样例。

椅子1米、2米组发生严重错误，3米组本轮较接近参考值。不能据此得出“距离越近越差”的一般结论：近处的窄上沿、重复网纹和不同背景，与远处的实体靠背外观不同。这批椅子图应保留为失败案例，不能从总体统计中删掉。

全部43对合计平均绝对误差58.1 cm、平均相对误差44.1%，主要受6对椅子严重错误影响；按目标和距离分组更方便定位问题。

## 4. 对输出和参数的建议：先审阅，尚未修改

**建议下一步优先处理“错误匹配仍输出距离”，然后比较测距精度。** 识别可以给出物体位置，但不能修复上述左右对应错误。

1. **先补充输出解释。** 用户界面可显示现有的有效比例、四分位距，以及“像素数量通过”和“匹配质量判断”的区别。建议新增可追查的 ROI 视差中位数、左右对应一致性通过比例和质量状态；具体字段与判定方法待批准。有效比例不写成“准确率”或“置信度”。
2. **再加强匹配检查。** 可独立计算右视差图，检查左图找到的右图位置是否能反向找到原位置；再结合局部纹理和区域深度分布决定保留哪些点。这样能针对错配，而不是只提高有效比例门槛。单独右视差会增加一次匹配计算，需要一起比较耗时。
3. **参数做少量对比。** 当前128像素搜索范围已覆盖这批0.5～3米对应的理论视差范围，没有证据表明应先扩大范围。可在用户批准后比较5/7/9像素窗口，并同步设置灰度匹配的 `P1=8×窗口²`、`P2=32×窗口²`；再考虑唯一性等参数。每次在同一批固定ROI上比较全部结果，重点看6对椅子与0015是否改善，及纸盒是否退步。
4. **保留纸盒偏近这一观察。** 这批数据不能把整体偏差单独归因到某个SGBM参数；先处理明显错配，再看纸盒各距离误差的变化。本轮不改变相机几何关系。

目前已有数据足以开展这些算法比较，不新增采集任务。完成匹配改进后，再进入识别框与测距区域衔接；实时输入接入与树莓派测速放在离线结果能够解释之后。
