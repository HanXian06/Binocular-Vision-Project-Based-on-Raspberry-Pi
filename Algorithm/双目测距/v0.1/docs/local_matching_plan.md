# 步骤1：局部二维匹配对照（2026-11-21）

按用户授权执行。固定现有43对、原ROI、5.85cm参数；基线为不开反查的SGBM。新增独立实验入口，不改主测距入口。

方案：在原ROI以4像素间隔取固定网格点；9×9灰度图块；水平视差1～127；NCC比较同一行与上下±8像素两种范围。图块标准差至少5灰度级、相关度至少0.75、与排除峰周围±2像素后的次佳候选相差至少0.03。横向抛物线插值保留亚像素坐标。参数在查看结果前固定，不按参考距离选择对应点。

对照：原全ROI SGBM、相同网格SGBM、同一行NCC、二维NCC。对有效网格点仍取中位数；输出门槛为至少30个点且占网格10%，明确这不是稠密像素覆盖率。保存未通过质量门槛的候选及原因。原ROI窄上沿附近窗口可能覆盖其他表面，本轮不改ROI。

深度：用原P1/P2及左右完整二维坐标三角化，记录两侧重投影残差；主比较仍用矫正左坐标Z，另列原左坐标Z诊断。非零行差反映原模型不完全相容，三角化是折中解，不等于修复原模型。不用重投影残差再筛点，以免把纵向实验效果混入额外过滤。

- 必要测试：已知8像素横移和3像素纵移、弱纹理、重复候选、图像支持、三角化米单位与投影残差。

- 反馈共同可输出样本误差、输出比例、典型失败、耗时及下一步建议。
