## 输出机制

- OpenCV remap 使用冻结的左右K/D/R/P执行校正。
- StereoSGBM 比较灰度小块、多方向汇总匹配代价及平滑惩罚。固定起步配置：视差范围0～127、窗口5、P1=200、P2=800、uniquenessRatio=10、disp12MaxDiff=1、散斑窗口100。
- 原始SGBM视差除以16成为像素视差；使用配套Q矩阵重建米单位Z。
- 按左、右匹配窗口的真实图像支持、视差和深度合法性过滤；右侧支持检查使用 x-d。
- ROI中位数为输出深度，IQR描述有效深度的分散程度；达到30有效像素、10%有效率时 available=true。它反映能否形成区域统计，不等于匹配全部正确。
- 参考距离只参与最后的误差计算；未用它拟合补偿、挑选深度区间或改变相机参数。

## 必要验证

5项功能验证全部通过：

1. 已知视差8像素、焦距100像素、基线0.0585米时，Q重建得到0.73125米。
2. 无效/非正深度不进入统计，有效数量不足时返回空距离及原因。
3. 左点检查右侧 x-d 处的图像支持，而不是检查相同x。
4. 合成左右图具有8像素平移，SGBM得到正确正视差，确认16倍缩放。
5. 越界ROI明确报错。

同一真实样例重复运行，数值视差、深度（包含NaN位置）、有效掩码与区域统计完全一致。冻结参数SHA为 `9740a0c42f90be52148122be90d507f061546bcc596a4ad4efe62dd1076e262a`。这些检查没有扩展到批量测距或标定重估。

## 怎样审阅
