更新者：陈珂乐。2026-11-23首次发布。固定人工表面后生成13个区域：内缩完整区、中心区、左右条带和3×3九宫格；按全部候选并集去重后取中位数。完整区已包含子区，不能把它当作背景排除算法。参考距离仅在最后计算误差，不参与选区。

最终结果：v0.1书本25/25、MAE13.14cm，人物9/9、27.92cm，椅子9/9、40.84cm；v0.2分别为25/25、13.83cm，9/9、24.68cm，0/9无距离。子区统计用于分析空间差异，不从中挑误差最小的作为结果。
