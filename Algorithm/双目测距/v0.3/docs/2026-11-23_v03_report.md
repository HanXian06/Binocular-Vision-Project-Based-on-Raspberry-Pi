# v0.3开发报告：YOLO检测到目标测距

日期：2026-11-23。完成用户批准的D2＋M1＋G1、本地真实模型测试及人工ROI对照。修改识别接口另存于v0.3，未覆盖原仓库、旧版本、旧调用账本，未上传。

## 1. 完成情况

已实现：YOLOX结构化输出、校正左图检测、类别表面适配、固定13区统计、原SGBM深度、逐检测对象距离/状态、可重复离线入口。已经完成43对本地推理。

未实施：实时相机循环、上板测试、上下行稠密搜索、独立右图反查、深度聚类、实例分割、训练或更换权重。代码可接入帧组时间，但静态数据没有可靠时间记录时保存null。

## 2. 算法执行与改动

- 检测：原仓库YOLOX-Nano 416模型；保留BGR、左上114补边、原解码、objectness×class分数及按类NMS。置信度0.35，NMS IoU 0.45，未调参。
- 接口：增加infer结构化输出；annotate消费已有结果，显示不触发第二次推理。Windows中文路径不能直接读模型，修复为读相同文件字节再加载，权重不变。
- D2：book整框经协议内缩5%；person框内x20%～80%、y15%～65%；chair框内x5%～95%、y5%～55%。所有框都在校正左图坐标中。
- M1：原SGBM副本，原5像素窗口、128范围和原惩罚/过滤参数。不进行上下搜索。
- G1：原Q，矫正左坐标Z，完整表面窗口支持；30个有效位置和10%通过比例门槛。候选并集去重后中位数，不按参考值选择区域。

输入输出、参数作用及备选方案已归档于 [方案](2026-11-23_v03_plan.md)。各版本原文件保留，来源与模型指纹见references/source.json。

全图共保留100个检测结果，其中61个属于支持类别并输出距离；14/43指本数据集中带参考距离的目标，而非全图只有14个物体被检测。图中其他椅子/人物全部保存，不能将背景椅子的检测误当作前景参考椅子。

目标关联只在评估阶段使用：同类检测覆盖人工表面≥50%，按覆盖率、再按置信度关联；不用距离挑框。这是固定参考目标的覆盖评估，不是完整检测mAP，原数据没有标全场景所有物体。

## 4. 原图检测与校正图检测对照

为定位漏检，补充同权重同阈值的原图左侧检测43次；不更改正式测距结果，不重算SGBM。人工表面经既有校正查找表映射到原图采样点，按覆盖关联参考目标。

| 目标 | 原图检出 | 校正左图检出 |
| --- | --- | --- |
| 书本 | 0/25 | 0/25 |
| 人物 | 9/9 | 9/9 |
| 椅子 | 6/9 | 5/9 |

书本漏检不能单独归因于校正输入，因为原图也未检出book目标。部分图片出现laptop、cell phone等其他标签，全部原始类别结果已保存，不能更名成book后算识别成功。

椅子校正输入少命中1个参考目标，说明输入变换会影响部分检测，但不足以解释所有漏检。可核对 `results/detection_input_control/raw_detections.json` 与主结果，不在本轮偷偷切换检测路径。

## 5. 原因定位

1. **检测层**：本轮书本没有被当前阈值下的原模型识别为book；近处前景椅子0004～0006未检出，但同图左侧其他椅子被检出。0011也未关联到参考椅子。因此不能用继续改人工ROI解决这些自动链路缺口。
2. **选区层**：人物和已检出椅子自动/人工共同样本的误差接近，说明本次固定自动适配没有造成大幅新增误差，但不表示类别比例已经能准确分割任意姿态。
3. **匹配/采集层**：人物0015自动约2.019m、人工约2.025m，参考2.98m。自动与人工都保留大偏差，不能把这个问题归为框的位置。已有拍摄变化及几何残差分析仍适用。
4. **统计层**：已有中位数不会判断哪簇一定属于物体；本轮没有新增聚类或分割，保留原方法作为基线。

## 6. 耗时与验证

本机校正左图YOLO推理/解码平均约20.1ms，SGBM及深度/有效掩码约65.7ms；不含全部读取、显示和写盘。没有上板计时，不据此给树莓派帧率。

5项测试通过：预处理颜色/补边、框坐标/置信度解码、按类NMS、表面映射/空深度、中文路径模型读取。另核对43对人工路径与上一轮冻结v0.1结果完全一致，模型字节数及Git blob/SHA-256指纹一致，旧版本未改。

本轮主评估43次YOLO、43次SGBM；输入对照另43次YOLO，无额外SGBM。最初一次模型路径加载失败，没有执行推理；记录另存。没有重置或消耗上次ROI调试/最终评估账本。

## 7. 下一步候选，待审阅

### N1：检测漏检定位与检测输入策略（建议优先）

功能：弄清书本未检出是候选置信度低还是类别不对，并验证椅子少检的来源。

候选A：保留原模型，输出目标附近的NMS前类别/分数，固定对照阈值0.25/0.35/0.45；阈值降低会增加候选和误检，不能只统计命中。该诊断不伪造book框，不改测距。

候选B：原图检测后将框/表面掩码映射到校正图。检测使用原训练外观，原图椅子对照多命中1张；需要额外坐标映射，不能只把原图矩形数值当校正图坐标，非线性畸变下宜映射掩码。416、NMS 0.45固定，是否切换由用户批准。

候选C：换更强检测器或微调原模型。可能改善目标外观不匹配，但需要对应模型、标注及推理代价评估；当前没有证据承诺收益，不在本轮执行。输入416为当前模型要求，不能仅把配置改640就称升级模型。

推荐先A明确失效位置，再决定B/C。交付检测候选、误检/漏检、目标框图和时间，与本轮固定结果对照，未获批准不运行新阈值。

### N2：v0.1稠密上下搜索

功能：处理当前几何下同行搜索的对应残差。候选为纵向最小局部代价＋SGM聚合、输入配准后SGBM、SGBM初值的二维局部修正；与既有v0.1融合方案一致。原OpenCV SGBM没有上下搜索开关。

建议另行选定实现路径；若选自定义代价体＋SGM，参数先比较纵向0/2/4/8像素，横向范围128，窗口5，代价尺度一致才沿用P1/P2=200/800。扩大范围增加计算和歧义，需同时保存dx/dy与投影残差。交付共同样本误差、输出率、内存及耗时，不引入Shi–Tomasi前置删点。

优先完成检测问题定位后，在固定真实YOLO结果上比较新匹配器，避免同时改变检测、选区和测距。两项候选均尚未执行。
