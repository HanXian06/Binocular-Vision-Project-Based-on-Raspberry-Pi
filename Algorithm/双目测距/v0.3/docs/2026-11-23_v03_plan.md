# v0.3已批准方案归档

用户先批准D2＋M1＋G1，再明确批准v0.3本地开发、另存识别代码及真实YOLO与人工ROI对照。本文件整理此前已说明并批准的方案，不将后续建议算作批准。

| 算法/环节 | 原理及输入输出 | 候选比较与本轮选择 | 参数及影响 |
| --- | --- | --- | --- |
| YOLOX-Nano结构化接口 | 输入校正左图；按原网络解码和按类NMS输出类别、分数、xyxy | 原模型复用，另存infer接口；换模型和实例分割不实施 | 416输入、置信度0.35、NMS IoU 0.45；阈值提高会减少候选/增加漏检，全部固定 |
| D2类别表面适配 | 检测框按类别比例生成表面，再生成固定13区 | 整框中位数、相对表面、多模型分割可选；本轮相对表面 | book整框后协议内缩5%；person x20%～80%、y15%～65%；chair x5%～95%、y5%～55%；固定，不逐图改 |
| M1原SGBM | 校正左右灰度图→稠密视差；利用邻域约束选视差 | 本轮原v0.1；上下搜索另行开发，不使用Shi–Tomasi/NCC替代 | min=0、范围128、窗口5、P1=200/P2=800、唯一性10、散斑100/2、内置disp12=1，固定 |
| G1 Q深度与固定汇总 | 输入稠密视差、原Q；输出矫正左坐标Z、逐目标状态 | 中位数复用；聚类后统计暂不实施 | 5.85cm基线、30点/10%门槛，完整表面窗口支持，候选位置去重不重计 |

流程：左右原图/帧组信息→校正→左图检测→D2→M1深度→G1→最后绘制。算法输入不带任何绘制文字或检测框。保留原BGR、等比缩放和左上补边解码。

评估：固定43对；自动路径先完成，再用冻结人工表面框在同一深度图统计。预先固定的关联规则为同类检测框覆盖人工表面≥50%，优先覆盖率再置信度，仅用于离线对照，不影响检测结果或测距。多目标全部保存，不以距离挑目标。

输出：逐对象数据、自动/人工区域图、稠密数组、参考目标检测/测距状态、共同样本误差、耗时、原模型指纹和代码来源。所有文件位于v0.3，旧版本、原仓库和旧调用账本不改。不上传，不重训，不上板，不自动调参。
