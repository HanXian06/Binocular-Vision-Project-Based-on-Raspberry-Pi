# 固定 58.5 mm 基线的标定修正包（2026-11-11，候选参数共享）

## 结论先看

已按用户授权完成**固定基线约束下的候选标定重估**，不是简单放大旧平移向量。旧结果保留于相邻的 Calibration1105。本包经用户授权单独发布；本次发布没有重新运行标定、识别、视差或测距。

基线已满足 **58.5 mm**，但现有图片在固定内参下的几何拟合并未改善，因此本包参数是 **candidate_not_accepted（候选、未验收）**，不能标记为正式可靠标定。

| 指标 | 旧直接标定 | 新固定基线候选 |
| --- | --- | --- |
| 基线 | 27.99 mm，自由求解 | 58.50 mm，严格输入约束 |
| 双目重投影 RMS | 3.975 px | 5.166 px |
| 各对上下偏差中位数的中位数 | 1.84 px | 2.24 px |

基线符合输入是约束的结果，不是精度验证。优化收敛也不代表模型与数据一致或满足测距要求。基线值应继续使用用户已核验的 58.5 mm，不因本次误差而否定实测值。

## 改了什么、为什么

- 保持原来的 K1/K2 内参、D1/D2 畸变不变，避免未经授权扩大到另一套内参方案。
- 使用现有 Data1105 PartA 的 20 对原图，格长 15 mm、8×6 内角点、每路 640×480。
- 左右角点仍用 OpenCV findChessboardCornersSB，并沿用旧版首尾方向点积的顺序统一规则；该启发式的正确性尚未独立确认。
- 用 SciPy least_squares 联合优化左右相机的相对旋转、平移方向及每对棋盘格在左相机坐标中的姿态。
- 平移采用 `T = 0.0585 × normalize([-1,u,v])` 参数化，强制长度为 0.0585 m；负 x 对应当前左到右坐标变换约定。没有强迫相机完全无上下/前后错位，也没有只改旧 T 的长度。
- 采用普通像素重投影最小二乘；不删除任何配对、不按结果挑照片。以旧直接标定和旧背景实验两种初值分别拟合，选择平方残差更小的一次；两次均收敛到很接近的目标值。
- 根据新 R/T 重新计算 R1/R2、P1/P2 和 Q，长度单位统一为米。

新 T（米）约为 `[-0.05805275393283657, 0.007149326762567201, 0.0010074163268324198]`，向量长度为 0.0585 m。不要把横向分量单独当成输入的两光心间直线距离。

## 验证范围

全量 20 对用于最终候选拟合。另做一次固定划分的外参检查：分析编号 3、8、13、18 留出，用其余 16 对重估相对姿态，再对 4 对计算校正后对应点上下偏差。

| 留出分析编号 | 上下偏差中位数 px | P95 px |
| --- | --- | --- |
| 3 | 1.20 | 5.89 |
| 8 | 5.51 | 7.97 |
| 13 | 1.38 | 4.37 |
| 18 | 1.86 | 4.33 |

此检查仍沿用先前用全部 20 对拟合的内参，所以是**外参留出检查，不是完全独立验证**。最终 20 对候选没有用这 4 对的表现来挑选方案。

参数自检：确认基线约束、内参逐元素不变、旋转矩阵正交且行列式为 1、Q 为有限数。另用已知相机姿态的合成数据检查零残差与优化回归，验证了坐标变换和单位链路；这不替代真实数据验收。

## 为什么没有宣布修正成功

这次已经补上真实基线约束，但数据与当前模型仍存在冲突。潜在原因包括左右角点对应、每对拍摄间棋盘格或相机移动、既有内参/畸变不适用等；本轮没有证实某个具体原因。

**目前不建议用这套参数替换正式测距配置，也不要求新增采集。** 后续如需推进，先给出针对角点顺序、逐对相对姿态与固定内参假设的检查方案，由用户选择后执行。本轮到此停止，不自行优化更多变量或筛图。

## 文件说明

- `results/fixed_baseline_candidate_meters.npz`：20 对联合拟合的新候选参数，未验收。
- `results/summary.json`、`results/per_pair.csv`：总体和逐对对照；CSV 包含原会话和原文件编号。
- `results/pair_XXXX_rectified.jpg`：6 对校正预览，绿线为水平检查线；只用于查看，数值参数不从 JPEG 读取。
- `results/validation_16pair_extrinsic.npz`：仅用于上述留出检查的 R/T 和划分，不是最终全量参数。
- `reference/direct_previous.npz`、`background_previous.npz`：旧参数，仅作对照与优化初值，没有修改。
- `data/`：本次标定的 40 张原图；不包含 PartB、PartC，不打包此前测距探索。
- `corners.npz`：对应的棋盘格米单位物点及左右像素角点。
- `input_manifest.json`、`source.json`：图片校验值、来源提交与用户确认尺寸。
- `scripts/fit_fixed_baseline.py`：复现整个标定及外参留出检查。
- `MANIFEST.json`：共享包文件 SHA-256 清单。

NPZ 中 K/D 为原图内参和畸变；R/T 满足 `X右 = R×X左 + T`；R1/R2 为校正旋转；P1/P2 为校正投影；Q 将像素单位数值视差转换为校正后左相机坐标中的三维点。T 与深度坐标以米计。输入尺寸、裁剪或镜头设置变化不能直接沿用。

## 复现（不是相机实拍程序）

本次环境：Python 3.13、OpenCV 5.0.0、NumPy 2.5.4、SciPy 1.18.1。SciPy 仅安装在本地项目的 `.calibration_deps`，未修改系统环境；该依赖目录不放进共享包。

在具备这些依赖的环境里，从本包目录运行：

```bash
python scripts/fit_fixed_baseline.py
```

脚本不联网、不上传、不打开相机，只读包内图片和旧参数。复现会覆盖本包 results 下同名输出，建议先复制包再运行。

本包经授权发布到 Calibration/Calibration1111/，不覆盖 Calibration1105。参数仍未验收，不能用正确基线替代精度证据。后续算法步骤依然等待用户指令。

## 与上一共享包的关系

[Calibration1105](../Calibration1105/README.md) 保留原直接标定和背景约束实验。本包使用同一批 PartA 数据和旧内参，新增固定 58.5 mm 基线的联合姿态重估及外参留出检查。它是供复查的候选版本，不是已经优于旧版的替代版本。两个共享包的 README 和参数均应配套阅读。
