# 标定结果说明

## 输入与已知条件

来源为 source.json 指定的 main 提交。当前只考虑横向双目。Data1105 PartA 共 20 对，每路 640×480，棋盘格为 8×6 内角点，格长采用用户提供的 15 mm，镜头中心间距为 58.5 mm。

左右按仓库 left/right 使用。物理相机与文件夹对应关系、安装是否全程固定尚未通过元数据独立确认；当前仓库缺少采集 metadata 和配置表，不能由文件名证明同步。仓库采集程序为先后取图。镜头中心间距是光心间距的近似测量值。

## 方法一：直接棋盘格标定

`fit_direct.py` 对每张灰度图使用 OpenCV findChessboardCornersSB 检测 48 个角点，统一左右遍历方向；以格长构造平面三维点，分别 calibrateCamera 得到内参与畸变，再 stereoCalibrate 固定内参求 R/T，最后 stereoRectify 求校正与重建参数。方向统一依据首尾角点方向点积，尚需检查这一启发式是否足够。

20 对均检测成功。左/右单目 RMS 为 0.349/0.343 px，双目 RMS 为 3.975 px。试算基线 27.99 mm，比实测 58.5 mm 小约 52.1%；部分对应角点校正后仍明显上下错位。

结论：单目结果可供继续研究；整套参数未验收，不可当作可靠正式双目标定。小的单目误差不能证明双目标定有效。RMS 是标定照片拟合误差，不是厘米级测距精度。

逐对结果在 `per_pair.csv`。其中 pair_0001～0020 是两段按路径排序后的分析编号，请同时使用 source_session、original_pair 定位原图，不能仅按后缀推断原文件。

## 方法二：背景约束实验

`fit_background.py` 使用方法一的内参与畸变，排除棋盘格角点包围框附近区域，使用 SIFT 特征和描述子匹配（比例阈值 0.7），汇总 20 对背景候选点；去畸变后以 RANSAC 本质矩阵和 recoverPose 求相对姿态，再将平移方向乘以实测间距 0.0585 m，求校正参数。

1320 个候选匹配中保留姿态内点 177 个；这些拟合内点校正后上下偏差中位数 0.51 px，95% 分位约 1.00 px。

这是实验备选：58.5 mm 是人为输入的尺度，不是算法独立估计的基线。指标只计算拟合内点，存在筛选偏差，不代表全部图片。棋盘格外背景也可能有移动、重复纹理或近似平面，且内参仍来自未独立验证的单目标定。当前不能宣布该方法已修复问题或完成验收。

## NPZ 参数怎么读

两个参数文件均使用 NumPy np.load，长度单位为米，图像坐标以像素计，适用输入为当前 640×480、相同裁剪和镜头设置。背景文件缺少尺寸字段，统一以 source.json 为准。

| 字段 | 含义 |
| --- | --- |
| K1/K2，3×3 | 左右相机内参；焦距、主点单位为像素 |
| D1/D2，1×5 | 畸变系数，顺序 k1,k2,p1,p2,k3 |
| R，3×3；T，3×1 | 原左相机坐标到原右相机坐标，X右=R×X左+T；T 单位米 |
| R1/R2 | 左右校正旋转 |
| P1/P2，3×4 | 校正后的投影矩阵 |
| Q，4×4 | 将数值视差转换为校正后左相机坐标中的三维点 |

相机坐标通常 x 向右、y 向下、z 向前。后续由 Q 得到的 z 为校正坐标系光轴深度，并非空间直线距离；视差需为像素单位，不能传入彩色显示图。改变图像模式、裁剪或镜头配置后不能直接沿用。

阅读示例（只读参数，不执行识别或测距）：

```python
import numpy as np
with np.load('calibration/direct/trial_calibration_meters.npz') as p:
    print(p['K1'])
    print(p['T'])  # 米，当前试算未验收
```
