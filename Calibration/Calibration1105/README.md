## 包内内容

- `data/PartA(1-8)`、`data/PartA(9-20)`：20 对标定原图，共 40 张；没有改图或重命名。
- `calibration/direct`：直接棋盘格试标定，含参数、误差表与部分校正图。
- `calibration/background`：背景约束实验参数及统计，不能称为正式标定。
- `scripts`：两种标定的复现脚本。本次只调整包内路径和一处错误的单位注释，未修改标定算法，未重跑标定。

本包仅包含标定材料，不包含正式识别或测距模块。此前探索性结果不作为项目里程碑或交付结果。
