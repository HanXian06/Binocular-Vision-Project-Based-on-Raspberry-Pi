# 树莓派双目视觉：测距与目标识别

本项目以树莓派为硬件平台，逐步完成双目取图、标定、测距与目标识别融合。更新记录按北京时间、日期倒序排列；PR 更新日与合入日不一致时分别注明。记录中的“建议下一步”是讨论顺序，不是自动开发授权。

## 当前进展（2026-11-11）

- **独立识别已部署并运行**：硬件组员已在树莓派 5、双 OV5647 上使用 YOLOX-Nano 进行识别并给出反馈。PR #3 和模块说明记录了双路取图、推理和桌面预览；每路约 5 fps 是该次测试记录，不代表所有条件或整个双目测距系统的性能。
- **标定尚未验收**：有两个并存共享包，没有指定正式默认参数。新包满足 58.5 mm 固定基线，但拟合误差未改善，不能直接认定为正确标定。
- **正式测距与融合尚未开展**：旧的离线探索不算正式模块或最终精度成果。连续取流不等于曝光同步，识别部署成功不等于双目测距成立。
- 当前主线建议：标定核查与验收 → 数值视差 → 人工区域测距 → 可靠性判断 → 接入现有识别结果 → 连续输入的时间配对、部署和评估。识别原型继续保留，不必重新起步或先更换模型。

## 使用入口

- **识别**：先阅读 [识别模块 README](Algorithm/Dual-Camera-YOLO/README.md)。按模块记录，已部署路径为树莓派 `/home/pi/pi-dual-yolo/`，在树莓派图形桌面执行该目录的 `start.sh` 或桌面快捷方式。它做两路独立识别，不输出双目距离。
- **标定复现**：分别阅读两个包的 README，确认依赖与参数状态；复现可能覆盖包内同名结果，先复制一份，不能用旧包参数静默替换新包或反之。
- **静态采集**：如以后另获授权需要采集，从仓库根目录运行下方命令。当前不新增非必要采集任务。

```bash
python "Algorithm/Algo_Capture/capture_pairs(dualcam intergreted).py" --out "Dataset/new_capture_01"
```

`--out` 必须不存在。默认相机编号 0、1，左右对应关系应按实物确认。点击窗口后 S 拍摄定格，再 S 保存，W 放弃，Q 退出；此程序轮流取图，不等同于双路常开识别程序。已有参数均按每路 640×480 及原拍摄配置建立，改变成像模式、焦距或安装关系后需重新核查。
