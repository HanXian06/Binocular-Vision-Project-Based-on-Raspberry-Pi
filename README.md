# 树莓派双目视觉：测距与目标识别

本项目实现树莓派双目取图、目标识别与离线测距。更新记录按北京时间倒序排列，历史记录中的计划保留当时语境；当前工作以下述进展及共享开发路线为准。

## 当前进展（2026-11-23）

原YOLOX-Nano双路识别已由硬件组员部署；本次新增的是**v0.3本地离线检测与测距闭环**，尚未接入树莓派实时双目测距。算法参数沿用background1105，基线0.0585m；Calibration1105/1111两包均保留，不把后者默认替换启用。

| 版本 | 方法与用途 | 固定43对测试结果 | 主要问题 |
| --- | --- | --- | --- |
| [v0.1](Algorithm/双目测距/v0.1/README.md) | StereoSGBM全图同一行匹配，Q转深度，表面区域中位数 | 固定人工表面协议：书本25/25、MAE13.14cm；人物9/9、27.92cm；椅子9/9、40.84cm | 输出覆盖较好，椅网等场景错配明显；反查未改善整体 |
| [v0.2](Algorithm/双目测距/v0.2/README.md) | Shi–Tomasi角点＋局部NCC上下±8搜索＋三角化 | 同一协议：书本25/25、13.83cm；人物9/9、24.68cm；椅子0/9 | 稀疏数量门槛曾导致远书本无输出；椅网重复纹理仍难匹配 |
| [v0.3](Algorithm/双目测距/v0.3/README.md) | YOLOX-Nano→D2类别表面→M1原SGBM→G1固定区域汇总 | 自动：书本0/25；人物9/9、29.39cm；椅子5/9、23.42cm | 主要新增自动链路；书本及部分椅子漏检，剩余测距误差尚在 |

MAE是与现场距离记录的平均绝对误差，不是像素重投影误差。v0.3同样本人工对照：人物9对27.92cm、椅子5对23.13cm。**椅子5对的23.42cm不能直接与v0.1全9对40.84cm比较。** v0.3参考目标有距离14/43，场景中其他物体不计入这个成功数。

为何开发v0.3：从人工ROI评估转为已有YOLO自动识别选区，采用v0.1覆盖较好的稠密匹配，避免依赖v0.2远目标的稀疏点数。模型仍是原权重；自动框不能保证远书本被检出。原图检测对照同样书本0/25，故不能仅归因于校正。当前人工/自动框共同样本误差接近，后续应分开定位检测、背景混入、匹配与几何因素。

- [固定ROI逻辑及静态对照](Algorithm/双目测距/roi_protocol/README.md)

## 两个标定共享包

共同输入：Data1105 PartA 共 20 对、每路 640×480、8×6 内角点、格长 15 mm；用户已核验两镜头中心间距 58.5 mm。像素拟合误差不是实际距离误差，不同方法、不同统计样本的指标不能直接混比。

| 共享包 | 内容与更新 | 可靠性与用途 |
| --- | --- | --- |
| [Calibration1105](Calibration/Calibration1105/README.md) | 首次共享：原图、棋盘格直接标定、背景约束实验、逐对误差、预览、参数说明及复现脚本 | 原文件完整保留。直接标定双目 RMS 3.975 px，试算基线 27.99 mm；背景方案把 58.5 mm 作为输入尺度，拟合内点上下偏差中位数约 0.51 px，不能当作独立验证；两者均未验收 |
| [Calibration1111](Calibration/Calibration1111/README.md) | 本次新增：固定旧内参/畸变，基线严格约束 58.5 mm，联合优化相对旋转、平移方向与棋盘格姿态；含新候选参数、对照、留出检查和复现脚本 | 不覆盖旧包。新 RMS 5.166 px，高于原版；各对上下偏差中位数的中位数由约 1.84 升至 2.24 px，未验收，不设为默认参数 |

新包的 16 对拟合、4 对留出检查仅检查外参：旧内参曾用全部 20 对，故不是完全独立验证。基线正确是输入约束得到的结果，不是算法独立估计或精度通过的证据。

### 2026-11-23 — YOLOE 双摄识别与流畅预览（`yoloe-stereo-preview`）

更新者：黄启明（kabuda-pixel）。

- **建议下一步**：从两路相机补采漏检样本，使用同一批图和一致的评估规则检查识别改进。测距接入应在独立实验中验证。

## 使用入口

- **识别**：先阅读 [识别模块 README](Algorithm/Dual-Camera-YOLO/README.md)。按模块记录，已部署路径为树莓派 `/home/pi/pi-dual-yolo/`，在树莓派图形桌面执行该目录的 `start.sh` 或桌面快捷方式。它做两路独立识别，不输出双目距离。
- **标定复现**：分别阅读两个包的 README，确认依赖与参数状态；复现可能覆盖包内同名结果，先复制一份，不能用旧包参数静默替换新包或反之。
- **静态采集**：如以后另获授权需要采集，从仓库根目录运行下方命令。当前不新增非必要采集任务。

```bash
python "Algorithm/Algo_Capture/capture_pairs(dualcam intergreted).py" --out "Dataset/new_capture_01"
```

`--out` 必须不存在。默认相机编号 0、1，左右对应关系应按实物确认。点击窗口后 S 拍摄定格，再 S 保存，W 放弃，Q 退出；此程序轮流取图，不等同于双路常开识别程序。已有参数均按每路 640×480 及原拍摄配置建立，改变成像模式、焦距或安装关系后需重新核查。
